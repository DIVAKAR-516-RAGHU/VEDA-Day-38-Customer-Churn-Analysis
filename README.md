# Customer Churn Prediction & Retention Analysis

## Project Overview
This project develops a machine learning workflow to predict customer churn in a subscription-based telecommunications business. It also analyzes customer churn patterns and proposes data-driven retention strategies.

## Internship Details
- **Program:** VEDA AI & ML Internship
- **Day:** 38 of 45
- **Project:** Customer Churn Prediction & Retention Analysis

## Objectives
- Clean and preprocess customer data.
- Perform exploratory data analysis (EDA).
- Train and compare multiple classification algorithms.
- Evaluate models using appropriate classification metrics.
- Identify important churn-related features.
- Develop a customer churn prediction function.
- Recommend targeted customer retention strategies.
